# Задача для открытого урока
Дан список учителей и учеников. Перед каждым именем указано, учитель это или ученик. Пример:

```
Учитель Иван Лозница
Ученик Анна Алексеева
Учитель Алексей Воронцов
Ученик Илья Кузнец
Ученик Бернард Сандеро
Ученик Борис Воронцов
Ученик Алексей Вороненко
Ученик Илья Кузнецов
```

Программа должна вывести в стандартный вывод имена и фамилии отсортированные в алфавитном порядке.

### Пример работы программы
До:
```
Учитель Иван Лозница
Ученик Анна Алексеева
Учитель Алексей Воронцов
Ученик Илья Кузнец
Ученик Бернард Сандеро
Ученик Борис Воронцов
Ученик Алексей Вороненко
Ученик Илья Кузнецов
```

После:
```
Алексей Вороненко
Алексей Воронцов
Анна Алексеева
Бернард Сандеро
Борис Воронцов
Иван Лозница
Илья Кузнец
Илья Кузнецов
```

__Примечание__: Функция `sorted_classroom_list()` должна принимать ссылку на `Classroom` и возвращать строку – отсортированный список людей в классе. Вы можете модифицировать структуры `Teacher` и `Student`, но у них должно оставаться поле `name` - полное имя человека. Парсинг файла с именами уже реализован. Программа должна вывести список людей в классе в стандартный вывод.


## Сборка и запуск проекта 
Требования:
* Компилятор С++14 и выше
* cmake
### Сборка через cmake CLI 
``` sh
cmake -B build
cmake --build build
```
Если вам нужно указать другую версию стандарта, то
``` sh
cmake -B build -DSTD=<версия>
cmake --build build
```
### Запуск
Чтобы запустить проект в той же директории выполнить
``` sh
./build/build classroom.txt
```
